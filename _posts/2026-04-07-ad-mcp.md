# AI로 AD 운영을 자동화할 수 있을까? — MCP 활용 실험

> ADFS 편에 이어, 이번엔 **Active Directory** 일상 운영 작업을 MCP로 자동화한 실험임.  
> 로컬 테스트 환경 기준이며, 보안 고려사항을 포함함.

---

## ADFS보다 AD가 더 잘 맞는 이유

[이전 포스팅](/ai/adfs-mcp/)에서 ADFS 운영 자동화를 다뤘는데, 솔직히 AD 쪽이 MCP와 더 잘 맞음.

| 구분 | ADFS | AD |
|------|------|----|
| 작업 빈도 | 낮음 (설정 변경 간헐적) | 높음 (매일 반복) |
| 자연어 질의 적합성 | 보통 | 매우 높음 |
| Helpdesk 자동화 가능성 | 낮음 | 높음 |

ADFS는 설정 변경이 드문 반면, AD는 계정 잠금 해제, 신규 입사자 계정 생성, 비밀번호 만료 확인 같은 **매일 반복되는 작업**이 넘침.  
"계정 잠겼어요" 티켓 하나 처리하는 데 매번 ADUC 열고 찾고 클릭하는 과정, AI한테 맡길 수 있으면 어떨까?

---

## 아키텍처 구성

ADFS 편과 동일한 구조임. DC(도메인 컨트롤러)에 Python을 설치할 필요 없이, 개발 PC에서 PowerShell Remoting으로 원격 실행함.

```
[개발 PC]                              [도메인 컨트롤러]
  Claude Desktop                         Windows Server
       │                                      │
  MCP Client                            PowerShell
       │                                      │
  MCP Server (Python/FastMCP) ── WinRM ──▶ Get-ADUser
                                            Unlock-ADAccount
                                            New-ADUser
                                            Get-ADGroupMember 등
```

### 준비 환경

| 항목 | 내용 |
|------|------|
| 개발 PC | Windows 10/11, Python 3.10+, Claude Desktop |
| 도메인 컨트롤러 | Windows Server, PowerShell Remoting 활성화 (ActiveDirectory 모듈은 AD DS 역할 설치 시 기본 포함, RSAT는 DC가 아닌 관리 PC용) |
| 라이브러리 | `fastmcp`, `pywinrm` |

```python
import base64
import json
import os
import re
import secrets
import string
import subprocess
from fastmcp import FastMCP

mcp = FastMCP("AD Ops Server")


def require_env(name: str) -> str:
    """환경변수 필수. 기본값(평문 비밀번호 등)으로 동작하지 않음"""
    value = os.getenv(name)
    if not value:
        raise RuntimeError(f"환경변수 {name} 가 설정되지 않음")
    return value


# 예: DC_SERVER=dc01.bwcorp.com, DC_USER=BWCORP\svc-mcp-ad (전용 서비스 계정)
DC_SERVER = require_env("DC_SERVER")
DC_USER   = require_env("DC_USER")
DC_PASS   = require_env("DC_PASS")

# 입력값 화이트리스트
ID_RE = re.compile(r"^[A-Za-z0-9._@-]{1,104}$")              # UPN / sAMAccountName
DN_RE = re.compile(r"^(OU|CN|DC)=[^,=]+(,(OU|CN|DC)=[^,=]+)*$")  # OU 경로


def check(value: str, pattern: re.Pattern, label: str) -> str:
    if not pattern.fullmatch(value):
        raise ValueError(f"{label} 형식이 올바르지 않음: {value!r}")
    return value


# 고정 래퍼: 사용자 입력은 코드 문자열에 넣지 않고
# 환경변수(JSON) → Invoke-Command -ArgumentList → param() 으로 값만 전달
PS_WRAPPER = r"""
$pw   = ConvertTo-SecureString $env:MCP_DC_PASS -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential($env:MCP_DC_USER, $pw)
$code = [Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($env:MCP_SCRIPT))
$json = [Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($env:MCP_ARGS))
$p = @{
    ComputerName = $env:MCP_DC_SERVER
    Credential   = $cred
    ScriptBlock  = [ScriptBlock]::Create($code)
}
$argList = $json | ConvertFrom-Json
if ($argList) { $p.ArgumentList = $argList }
Invoke-Command @p
"""


def run_ps_remote(script: str, *args) -> str:
    """PowerShell Remoting으로 DC에서 명령 실행.
    script: param() 으로 시작하는 고정 스크립트 (f-string 보간 금지)
    args:   param() 순서대로 전달할 값
    ActiveDirectory 모듈은 DC에서 자동 로드됨
    """
    env = os.environ.copy()
    env.update({
        "MCP_DC_SERVER": DC_SERVER,
        "MCP_DC_USER":   DC_USER,
        "MCP_DC_PASS":   DC_PASS,
        "MCP_SCRIPT": base64.b64encode(script.encode("utf-8")).decode(),
        "MCP_ARGS":   base64.b64encode(json.dumps(list(args)).encode("utf-8")).decode(),
    })
    cmd = ["powershell", "-NoProfile", "-NonInteractive", "-Command", PS_WRAPPER]
    try:
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=30, env=env)
        if result.returncode != 0:
            return f"[오류] {result.stderr.strip()}"
        return result.stdout.strip() or "(결과 없음)"
    except subprocess.TimeoutExpired:
        return "[오류] 명령 실행 시간 초과 (30초)"
    except Exception as e:
        return f"[오류] {str(e)}"


# ── Helpdesk 자동화 ─────────────────────────────

@mcp.tool()
def get_user_status(upn: str) -> str:
    """사용자 계정 상태를 조회함 (잠금, 만료, 비밀번호 등).

    Args:
        upn: 사용자 UPN 또는 sAMAccountName (예: user@bwcorp.com 또는 user01)
    """
    check(upn, ID_RE, "upn")
    script = """
        param($upn)
        $u = Get-ADUser -Filter {UserPrincipalName -eq $upn -or SamAccountName -eq $upn} `
             -Properties DisplayName, LockedOut, Enabled, PasswordExpired, PasswordLastSet,
                         PasswordNeverExpires, LastLogonDate, Department, Title
        if (-not $u) { "'$upn' 계정을 찾을 수 없음."; return }

        [PSCustomObject]@{
            이름              = $u.DisplayName
            UPN               = $u.UserPrincipalName
            활성화여부        = $u.Enabled
            계정잠금          = $u.LockedOut
            비밀번호만료      = $u.PasswordExpired
            마지막비밀번호변경 = $u.PasswordLastSet
            영구비밀번호      = $u.PasswordNeverExpires
            마지막로그온      = $u.LastLogonDate
            부서              = $u.Department
            직책              = $u.Title
        } | Format-List | Out-String
    """
    return run_ps_remote(script, upn)


@mcp.tool()
def unlock_account(upn: str) -> str:
    """잠긴 사용자 계정을 해제함.

    Args:
        upn: 사용자 UPN 또는 sAMAccountName
    """
    check(upn, ID_RE, "upn")
    script = """
        param($upn)
        $u = Get-ADUser -Filter {UserPrincipalName -eq $upn -or SamAccountName -eq $upn} -Properties DisplayName
        if (-not $u) { "'$upn' 계정을 찾을 수 없음."; return }
        if (-not (Get-ADUser $u -Properties LockedOut).LockedOut) {
            "$($u.SamAccountName) 계정은 잠겨있지 않습니다."; return
        }
        Unlock-ADAccount -Identity $u
        "✅ $($u.DisplayName) ($($u.SamAccountName)) 계정 잠금을 해제했습니다."
    """
    return run_ps_remote(script, upn)


@mcp.tool()
def get_locked_accounts() -> str:
    """현재 잠긴 계정 전체 목록을 조회함."""
    script = """
        Search-ADAccount -LockedOut |
        Select-Object Name, SamAccountName, LastLogonDate |
        Format-Table -AutoSize | Out-String
    """
    return run_ps_remote(script)


@mcp.tool()
def get_expiring_passwords(days: int = 7) -> str:
    """비밀번호 만료 임박 사용자를 조회함.

    Args:
        days: 만료 기준 일수 (기본값 7일)
    """
    days = int(days)
    # msDS-UserPasswordExpiryTimeComputed: DC가 계산한 만료 시각(FILETIME)
    # 세분화된 암호 정책(FGPP)이 적용된 사용자도 정확히 계산됨
    # 0(다음 로그온 시 변경) / 0x7FFFFFFFFFFFFFFF(만료 없음)는 제외
    script = """
        param($days)
        $threshold = (Get-Date).AddDays($days)

        Get-ADUser -Filter {Enabled -eq $true -and PasswordNeverExpires -eq $false} `
            -Properties 'msDS-UserPasswordExpiryTimeComputed', DisplayName, EmailAddress |
        ForEach-Object {
            $ft = $_.'msDS-UserPasswordExpiryTimeComputed'
            if ($ft -and $ft -ne 0x7FFFFFFFFFFFFFFF) {
                $_ | Add-Member -NotePropertyName ExpiryDate `
                     -NotePropertyValue ([datetime]::FromFileTime($ft)) -PassThru
            }
        } |
        Where-Object { $_.ExpiryDate -le $threshold } |
        Select-Object DisplayName, SamAccountName, EmailAddress,
            @{N='만료예정일';E={$_.ExpiryDate.ToString('yyyy-MM-dd')}} |
        Format-Table -AutoSize | Out-String
    """
    return run_ps_remote(script, days)


# ── 계정 생성 / 관리 ────────────────────────────

@mcp.tool()
def create_user(
    name: str,
    sam: str,
    upn_prefix: str,
    department: str,
    title: str,
    ou: str = "OU=Users,DC=bwcorp,DC=com"
) -> str:
    """신규 사용자 계정을 생성함.

    Args:
        name: 표시 이름 (예: 홍길동)
        sam: sAMAccountName (예: user01)
        upn_prefix: UPN 앞부분 (예: user01 → user01@bwcorp.com)
        department: 부서명
        title: 직책
        ou: 생성할 OU 경로 (기본값: Users OU)
    """
    check(sam, ID_RE, "sam")
    check(upn_prefix, ID_RE, "upn_prefix")
    check(ou, DN_RE, "ou")
    for label, v in (("name", name), ("department", department), ("title", title)):
        if not v or len(v) > 64:
            raise ValueError(f"{label} 길이가 올바르지 않음")

    # 초기 비밀번호: 고정값 대신 난수 생성 (대/소문자·숫자·특수문자 포함)
    # 결과 문자열(LLM 컨텍스트)에는 포함하지 않음 → 담당자가 별도 안전 채널로 재설정·전달
    pools = [string.ascii_uppercase, string.ascii_lowercase, string.digits, "!@#$%^&*"]
    chars = [secrets.choice(p) for p in pools] + \
            [secrets.choice("".join(pools)) for _ in range(16)]
    secrets.SystemRandom().shuffle(chars)
    init_pw = "".join(chars)

    script = """
        param($name, $sam, $upnPrefix, $department, $title, $ou, $initPw)
        $exists = Get-ADUser -Filter {SamAccountName -eq $sam} -ErrorAction SilentlyContinue
        if ($exists) { "'$sam' 계정이 이미 존재합니다."; return }

        $pw = ConvertTo-SecureString $initPw -AsPlainText -Force
        New-ADUser `
            -Name              $name `
            -SamAccountName    $sam `
            -UserPrincipalName "$upnPrefix@bwcorp.com" `
            -DisplayName       $name `
            -Department        $department `
            -Title             $title `
            -Path              $ou `
            -AccountPassword   $pw `
            -ChangePasswordAtLogon $true `
            -Enabled           $true

        "✅ 계정 생성 완료: $name ($upnPrefix@bwcorp.com) / 초기 비밀번호는 결과에 포함하지 않음 (담당자가 재설정 후 별도 전달, 최초 로그인 시 변경 필요)"
    """
    return run_ps_remote(script, name, sam, upn_prefix, department, title, ou, init_pw)


@mcp.tool()
def get_user_groups(upn: str) -> str:
    """사용자가 속한 그룹 목록을 조회함.

    Args:
        upn: 사용자 UPN 또는 sAMAccountName
    """
    check(upn, ID_RE, "upn")
    script = """
        param($upn)
        $u = Get-ADUser -Filter {UserPrincipalName -eq $upn -or SamAccountName -eq $upn}
        if (-not $u) { "'$upn' 계정을 찾을 수 없음."; return }

        Get-ADPrincipalGroupMembership $u |
        Select-Object Name, GroupScope, GroupCategory |
        Sort-Object Name |
        Format-Table -AutoSize | Out-String
    """
    return run_ps_remote(script, upn)


# ── 보안 감사 ───────────────────────────────────

@mcp.tool()
def get_inactive_accounts(days: int = 90) -> str:
    """지정 일수 이상 로그인하지 않은 계정을 조회함.

    Args:
        days: 비활성 기준 일수 (기본값 90일)
    """
    days = int(days)
    script = """
        param($days)
        $cutoff = (Get-Date).AddDays(-$days)
        Get-ADUser -Filter {Enabled -eq $true} -Properties DisplayName, LastLogonDate |
        Where-Object { $_.LastLogonDate -lt $cutoff -or $_.LastLogonDate -eq $null } |
        Select-Object DisplayName, SamAccountName,
            @{N='마지막로그온';E={
                if ($_.LastLogonDate) {$_.LastLogonDate.ToString('yyyy-MM-dd')} else {'없음'}
            }} |
        Sort-Object 마지막로그온 |
        Format-Table -AutoSize | Out-String
    """
    return run_ps_remote(script, days)


@mcp.tool()
def get_admin_accounts() -> str:
    """관리자 권한을 가진 계정 목록을 조회함 (Domain Admins, Administrators)."""
    script = """
        $adminGroups = @("Domain Admins", "Administrators", "Enterprise Admins")
        foreach ($group in $adminGroups) {
            Write-Output "=== $group ==="
            Get-ADGroupMember -Identity $group -Recursive |
            Where-Object { $_.objectClass -eq 'user' } |
            Get-ADUser -Properties LastLogonDate, Enabled |
            Select-Object Name, SamAccountName, Enabled,
                @{N='마지막로그온';E={
                    if ($_.LastLogonDate) {$_.LastLogonDate.ToString('yyyy-MM-dd')} else {'없음'}
                }} |
            Format-Table -AutoSize | Out-String
        }
    """
    return run_ps_remote(script)


if __name__ == "__main__":
    mcp.run()
```

## ⚠️ 보안 고려사항

AD MCP는 ADFS보다 훨씬 더 신중하게 접근해야 합니다.  
**읽기(Read)는 비교적 안전하지만, 쓰기(Write) 작업은 다름.**

### 작업별 위험도

| Tool | 작업 유형 | 위험도 | 비고 |
|------|----------|--------|------|
| `get_user_status` | 읽기 | 낮음 | 정보 유출 주의 |
| `get_locked_accounts` | 읽기 | 낮음 | 계정 목록 외부 전송 |
| `get_inactive_accounts` | 읽기 | 낮음 | 동일 |
| `get_admin_accounts` | 읽기 | 중간 | 관리자 목록 노출 위험 |
| `unlock_account` | **쓰기** | **높음** | AI가 실제 계정 변경 |
| `create_user` | **쓰기** | **높음** | AI가 계정 생성 |

### 반드시 고려할 사항

**1. 쓰기 작업은 승인 절차 추가 권장**

AI가 `unlock_account`를 바로 실행하는 게 편리하지만, 운영 환경에서는 "해제할까?" → 사람이 확인 → 실행 흐름을 유지하는 것이 안전합니다.

**2. Claude API 경유 데이터 주의**

읽기 결과(계정 목록, 관리자 목록 등)가 Anthropic 서버로 전송됨.  
운영 환경에서는 Ollama 같은 로컬 LLM 대체를 검토해야 함.

**3. 서비스 계정 권한 최소화**

MCP Server가 사용하는 DC 접속 계정에 최소 권한만 부여함.

```powershell
# 읽기 전용 운영이라면 Domain Users + Read 권한으로 충분
# 잠금 해제가 필요하다면 대상 OU에 lockoutTime 쓰기 권한(잠금 해제)만 위임
#   Account Operators는 대부분의 사용자·그룹을 생성·수정·삭제할 수 있는 고권한 그룹이라 부적합
# Domain Admins 계정을 MCP에 쓰는 것은 절대 비권장
```

### 폐쇄망 환경이라면 — Ollama 대안

```
[폐쇄망 내부]
  Ollama (로컬 LLM)
       │
  MCP Server (Python)  ── WinRM ──▶ DC (도메인 컨트롤러)

  → 외부 통신 없음, 계정 정보 내부에서만 처리
```

쓰기 작업이 포함된 AD 자동화는 특히 폐쇄망 + 로컬 LLM 조합이 현실적임.  
이 구성은 Mac mini M4 + Ollama 환경이 준비되면 별도로 다뤄볼 예정임.
